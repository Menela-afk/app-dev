# She's Dating the Gangster

## About the Movie

**She's Dating the Gangster** is a Filipino romantic drama film based on the bestselling novel by *Bianca Bernardino*.

> "Some love stories are worth remembering forever."

### Main Characters
- Athena Dizon
- Kenji Delos Reyes
- Kelay
- Lucas

### Why I Like This Movie
1. It has an emotional story.
2. The characters are memorable.
3. It teaches lessons about love, family, and sacrifice.
